Cross-Site Scripting (XSS) – Reflected XSS

Demonstrates Reflected XSS where an HTTP request parameter is immediately reflected back in the server's HTML response without proper sanitisation or output encoding.

An attacker crafts a URL containing a malicious JavaScript payload in the search parameter q. When a victim clicks on the crafted link, the server includes that unencoded script in the HTML response, causing the victim's browser to execute it within the application's origin context.
