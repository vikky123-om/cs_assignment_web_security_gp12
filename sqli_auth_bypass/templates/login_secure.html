🛡️ Other Mitigations (Theory)

Mitigation Description
Parameterised Queries Applied Use ? placeholders so the database driver separates SQL logic from data. This is the primary and most effective defence against SQL injection.
Input Validation with Allow-Lists Restrict usernames to expected patterns (e.g., alphanumeric only) using regular expressions. Reject any input containing special SQL characters like ', ;, or --.
Least-Privilege Database Accounts Run the application with a database account that only has the minimum permissions required (e.g., SELECT on the users table). Even if injection succeeds, the attacker cannot DROP tables or read other data.
Safe Error Handling Never expose raw SQL error messages to the user. Log detailed errors server-side and show a generic "Login failed" message to the client to prevent information leakage.
