SQL Injection – Authentication Bypass

This demo illustrates how SQL Injection can be used to bypass login authentication. When user input is concatenated directly into a SQL query string, an attacker can manipulate the query logic to log in as any user — or as the first user in the database — without knowing a valid password.

💉 Suggested Exploit Payload

Use this on the ⚠ Vulnerable Login page:

FieldValue
Username' OR '1'='1' --
Passwordanything

The injected fragment makes the WHERE clause always true and the -- comments out the password check, returning the first user in the table (usually admin).
