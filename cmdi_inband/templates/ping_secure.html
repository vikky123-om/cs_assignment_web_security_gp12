📖 Other Mitigations (Theory)

  • Avoid the shell entirely: Use language-native APIs (such as Python's socket library or dedicated ping packages) rather than calling OS binaries.
  • Parameterised execution with argument vector: When OS commands must be invoked, pass arguments as discrete array elements (e.g., subprocess.run(['cmd', arg], shell=False)) so arguments are not interpreted as commands by a shell.
  • Allow-list input validation: Whitelist only acceptable characters (e.g. alphanumeric characters, dots, and hyphens for domain/IP names). Reject or strip anything else.
