🎣 Attacker Page – POST CSRF

This page silently submits a hidden form to http://127.0.0.1:5005/profile using the POST method.
The browser automatically includes your session cookie with the request.

Since the vulnerable endpoint does not check for a CSRF token, the server accepts the forged request and changes your email to hacked@evil.com.

✅ Check the vulnerable profile — your email is now hacked@evil.com.

Note: The secure endpoint would reject this request with a 403 Forbidden because the CSRF token is missing.
