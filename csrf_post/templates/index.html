CSRF – POST-based Forged Action

The email-change endpoint (/profile) accepts POST requests without verifying a CSRF token. An attacker page can auto-submit a hidden form that changes the victim's email — the browser automatically attaches the session cookie, so the server thinks it's a legitimate request.

🧪 Steps to Reproduce

  1. Log in with one of the test accounts below.
  2. In a new tab, visit the 🎣 Evil Page.
  3. Return to the Vulnerable Profile — your email is now hacked@evil.com.
