🎣 GET-based CSRF Triggered!

This malicious page automatically triggered a hidden HTTP GET request to the target application:

<img src="http://127.0.0.1:5004/delete-account" style="display:none;">

Because the user had an active session cookie on 127.0.0.1:5004, the browser attached that session cookie to the image request. The vulnerable server accepted the GET request and deleted the active user's account!
