CSRF – GET-based Forged Action (Account Deletion)

Demonstrates how a state-changing action performed via a simple HTTP GET request can be forged cross-site.

In this application, an authenticated user's account deletion is performed via an unprotected GET link (/delete-account). Because browsers automatically load and issue GET requests for embedded images, links, or iframes, an attacker website can silently trigger this action using an invisible <img> element.

🎣 How the Exploit Works

  1. Log into the application as alice (or any user).
  2. View the profile page to confirm the account is active.
  3. In a new tab, open the Attacker Page.
  4. The attacker page contains: <img src="http://127.0.0.1:5004/delete-account" style="display:none">.
  5. The browser sends a GET request to /delete-account along with alice's session cookie.
  6. The server processes the request and deletes Alice's account without any consent or interaction!
